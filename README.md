One post on X that quotes make.fun's make-your-own-bounty post and asks people what bounty they would set: describe any task, set the reward and the entry fee, and keep a share of every fee people pay to enter. `POST.json` names the post's address; `main.ts` copies it to the harness output directory so the house can read the post's replies, reposts and quotes. The post itself is the entry — places go by replies + reposts + quotes at the deadline, top 50 share $250.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
